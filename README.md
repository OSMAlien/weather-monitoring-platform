# Weather Monitoring Platform

A full-stack meteorological observation and alert platform.

## Goals

This project demonstrates:
- Python programming
- REST API development
- PostgreSQL
- SQL
- React
- Git and GitHub
- Docker
- Linux
- CI/CD
- Testing
- Software architecture

## Planned Features

- Retrieve meteorological observations
- Store observations in PostgreSQL
- REST API for weather data
- Interactive dashboard
- Historical charts
- Weather alerts
- Authentication
- Automated testing
- Docker deployment
- CI/CD
